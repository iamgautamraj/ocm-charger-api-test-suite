# BUG-001: Invalid latitude (999) accepted; unrelated chargers returned instead of an error
Severity: Medium
Test case: TC-18

## Steps to reproduce
GET https://api.openchargemap.io/v3/poi/?output=json&latitude=999&longitude=77.5946&distance=10&maxresults=3&key=<KEY>

## Expected
A 4xx validation error, or at minimum an empty list (no charger is within 10 km of an invalid point).

## Actual
200 OK with chargers unrelated to the location, e.g. ID 511165 "Ionity Pudasjärvi", Finland
(lat 65.36, lon 26.99). "Distance" is null, so no location filter was applied.
Without maxresults, the same request returns 100 results.

## Notes
The same request with a valid latitude (TC-02) returns results with distances under 10 km.
